# C# Fundamentals

A collection of simple C# practice projects developed using WPF to learn and understand fundamental programming concepts.

## 📚 Projects

### 1. Switch Statements

A simple WPF application that demonstrates how switch statements execute different code blocks based on the selected option.

**Concepts Covered:**

* Switch Statements
* Case and Default
* Conditional Logic
* ComboBox and ListBox
* Event Handling

### 2. Object and Dynamic Types

A simple WPF application that demonstrates the use of `object` and `dynamic` types through a Student Details application.

**Features:**

* Enter student name, age, and department.
* Display student details.
* Store values using the `object` type.
* Work with values using the `dynamic` type.
* Calculate the student's age for the next year.

**Concepts Covered:**

* Object Type
* Dynamic Type
* `int.TryParse()`
* Type Conversion
* Runtime Operations
* Button Click Events

## 🛠️ Technologies Used

* .NET
